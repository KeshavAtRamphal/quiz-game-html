Chapter 1 — Transport Protocols

Summary

This chapter explores the TCP/IP suite, the foundational protocol set for all internet operations. It compares the four-layer DoD model with the five-layer modern TCP/IP model, which adds a dedicated Hardware Layer. Key distinctions are made between TCP (connection-oriented, reliable, three-way handshake) and UDP (connectionless, faster, no error checking). The chapter also introduces Netstat, a command-line utility for viewing network connections, routing tables, and interface statistics.

Chapter 2 — Name Resolution

Summary

This chapter focuses on the Domain Name System (DNS), explaining how human-readable names (like richfield.ac.za) are converted into IP addresses. It details the hierarchical structure of DNS, including Root, TLD, and Authoritative servers. DNS record types (A, AAAA, MX, CNAME, PTR) are covered alongside diagnostic tools: nslookup for DNS queries and nbtstat for NetBIOS troubleshooting.

Chapter 3 — Network Hardening

Summary

Network Hardening is a systematic process to reduce a network's attack surface and prevent unauthorized access. Key principles include Least Privilege, Defense in Depth, and Segmentation. Practical techniques include securing SNMPv3, implementing Switch Port Security, and using Dynamic ARP Inspection (DAI) to prevent spoofing. Isolating IoT and Guest networks via VLANs is also emphasized.
