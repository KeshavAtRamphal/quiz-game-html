# Quiz Game HTML

A collection of interactive, web-based revision quizzes designed to help students master core concepts in Information Technology and Business. These quizzes feature a clean user interface, instant feedback, and progress tracking.

---

## 📚 Covered Subjects

This repository contains dedicated quiz modules for the following topics:

* **Business** (`Kesh_Busines.html`): Organizational structures, business environments, and management.
* **Database Systems** (`Kesh_DBS.html`): SQL, normalization, relational design, and data integrity.
* **Information Systems** (`Kesh_INS.html`): Hardware, software, and data processing in business.
* **Networking** (`Kesh_Networks.html`): OSI model, protocols, IP addressing, and topologies.
* **Programming** (`Kesh_PROG.html`): Logic, data structures, and algorithmic thinking.

---

## 🚀 How to Play

1.  **Clone or Download** this repository.
2.  Open the folder on your computer.
3.  **Double-click** any of the `.html` files to launch the quiz in your web browser.
4.  No internet connection or server setup is required—it runs entirely in your browser!

## 🛠️ Built With

* **HTML5**: Content and structure.
* **CSS3**: Modern, clean styling for better readability.
* **JavaScript**: Interactive quiz logic, scoring, and feedback.
